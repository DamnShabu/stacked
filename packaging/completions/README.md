# Shell completions

Generated by `stacked completions`, committed so the packages can install them
without running the binary they are packaging. A test in
`crates/cordial-shell/src/completions.rs` fails when these fall out of step
with what the binary prints. To regenerate, from the repository root:

```bash
target/release/stacked completions bash > packaging/completions/stacked.bash
target/release/stacked completions zsh  > packaging/completions/_stacked
target/release/stacked completions fish > packaging/completions/stacked.fish
```
