Open-source Roblox for Linux

Stacked runs Roblox natively. No Wine, no emulator, no Android container.

Install Flatpak · x86-64 · needs a Vulkan GPU

Stacked runs Roblox’s official Android build natively on your machine — no Wine, no emulator, no Android container. It is GPL-3.0 and fully auditable: every line of what runs on your machine is published, which is the part most Linux Roblox clients cannot say. It is a fork of Cordial.

It is a command, not an app window. stacked starts Roblox, and the only window it opens is the game’s own. Profiles, settings, Roblox versions and plugins are subcommands — stacked help lists them — and errors are printed to the terminal rather than shown in a dialog.

Stacked fetches the Roblox build for you. It ships no Roblox code and never will, but stacked install is the whole of getting one. If Sober has already downloaded the same build, Stacked uses that copy where it lies rather than fetching it again; otherwise it downloads from a public APK mirror and verifies that Roblox's own signing certificate signed those exact bytes before installing. You can still point it at an APK yourself, with stacked config set roblox.apk PATH.

How Stacked compares to Sober, mocktail and Waydroid — including where they are better.

What you get

Profiles

Separate sign-ins, settings and caches. Each one is locked to a single running instance, so two clients can’t corrupt each other’s data.

Plugins

Discord presence, custom textures and sounds, and more. A plugin never gets a socket or a file — it asks, and Stacked does it.

Settings that tell you what happened

Every Roblox flag you set, and every conflict between them, printed at startup. stacked config lists every setting and what it is set to.

Stacked vs Sober vs Waydroid

Written to be useful rather than flattering. Sober is a good client and is what most people on Linux use today; if you want the smoothest path and do not care about source availability, use Sober.

Stacked
SourceOpen, GPL-3.0. Every line auditable.
HowNative. AOSP bionic linker, a bionic/glibc shim, a JNI VM in place of Android’s.
ExtensibleYes — a plugin API with brokered capabilities. No plugin gets a socket or a file descriptor.
Gets the buildstacked install downloads it and checks Roblox’s signature, or reads Sober’s copy.
MaturityYounger, and rougher, and a fork. See the status page before installing.
Sober
SourceNot available. vinegarhq/sober is an issue tracker; the client itself is not published.
HowNative, by its own account. Architecture not described in detail.
ExtensibleFastFlags, no plugin API.
Gets the buildDownloads it for you.
MaturityMature and widely used.
Waydroid
SourceOpen, GPL-3.0.
HowA full Android container. Roblox runs inside Android, which runs on your kernel.
ExtensibleNot for Roblox specifically.
Gets the buildYou install the APK inside Android.
MaturityMature, but it is general Android infrastructure and not a Roblox client.

The short version: Waydroid runs Android and Roblox happens to be in it. Sober runs Roblox and does not show you how. Stacked runs Roblox and shows you all of it.

Install

Not published yet. This is the command once the Flatpak remote is up; until then it fails, and building from source is the way in. 

flatpak remote-add --if-not-exists --no-gpg-verify \
    stacked https://damnshabu.github.io/stacked/repo

flatpak install stacked io.github.damnshabu.Stacked
flatpak run io.github.damnshabu.Stacked install
flatpak run io.github.damnshabu.Stacked

The third line fetches Roblox, the fourth starts it, and then you sign in and play. Nothing from Roblox is bundled or redistributed — Stacked downloads the official build to your machine and never re-serves it.

One thing to know first: if your account uses a passkey for two-factor, you cannot sign in yet. That is a missing piece in WebKitGTK rather than something Stacked can work around. Full status on GitHub.
