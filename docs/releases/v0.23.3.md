# Stacked 0.23.3

Roblox 2.746 starts again.

## What changed

- **Roblox 2.746.0.1266 loads.** On 0.23.2 it stopped before any window
  appeared, with `LOAD FAILED ... cannot locate symbol "AImageReader_delete"`
  ([headcount#53](https://github.com/DamnShabu/headcount/issues/53)). That
  build asks for nine Android video-decoding functions Stacked did not have.
  Stacked now answers them by saying it does not support them, so the engine
  loads. This is upstream Cordial's fix from
  [0.34.1](https://github.com/luohoa97/cordial/releases/tag/v0.34.1)
  (`aac0435`), taken as it is.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use Headcount
(formerly Roblox Manager), press Update, then launch your accounts again.

## What is still broken

- **Not yet seen running on this fork.** Upstream measured a 25 s run of
  2.746.0.1266 reaching its first frame on Cordial 0.34.1; on Stacked only the
  unit tests have run. If 2.746 still fails to start, please comment on
  [headcount#53](https://github.com/DamnShabu/headcount/issues/53) with the
  log.
- **Video that Roblox decodes through the Android image reader may not play.**
  Stacked tells the engine that path is unsupported. Nobody has yet reached a
  place in a game that uses it, so whether Roblox falls back or shows nothing
  is unknown. If a video stays blank, the log will have a line starting
  `[media] AImageReader_newWithUsage`; please include it in a report.
- Everything listed under [0.23.0](v0.23.0.md#what-is-still-broken) still
  applies.
