# Stacked 0.22.0

This release brings over the fixes Cordial made after Stacked forked from it,
plus a few of Stacked's own. **Most of them have not been played in Stacked
yet**: the test suite passes, and each one was checked upstream or against a
stand-in, as the list below says.

## Keyboard and text boxes

- **The keyboard should keep working after you join a game or switch
  servers.** Two causes are addressed. WASD and Space sometimes did nothing
  until the character respawned; Stacked now moves the pointer in place while
  a game starts, which upstream measured as walking in 4 of 4 joins against
  0 of 18 without it (`CORDIAL_NO_GAME_SEED=1` turns it off). And a chat or
  text box that was still focused when the game changed could keep the
  keyboard for itself; it is now let go when a new game starts. The second
  has not been seen on a live teleport.
- **Enter in a text box behaves as it does on a phone**: it sends a chat
  message or finishes the box, without leaving a newline behind.
- **Text boxes draw in the game's own colour and font**, and work on X11.
- **On X11, a held key is one press**, and the camera no longer spins or jumps
  from mouse movement that queued up while the game was busy.

## New

- **Record your gameplay to a video file.** Turn on `record_session` (and
  `record_audio` for the game's sound) with `stacked config set`, and F9
  starts and stops recording. Needs `ffmpeg`. F9 is left to the game unless
  one of those settings is on. See [recording](../recording.md).
- **Roblox's sign-in security check (the captcha) now opens**, so an account
  that is asked for one should be able to sign in. Not tried on a live check.
- **Choose a microphone** with the `audio_input` setting; `stacked
  audio-inputs` lists the names.

## Fixes

- **A start that freezes on one frame should be fixed at the cause (measured
  upstream, not here), and is restarted if it still happens.** Stacked restarts
  a stuck start up to twice; pressing
  Ctrl-C stops that.
- **Leaving fullscreen on Wayland should no longer crash**, and the game
  redraws while you drag the window's edge.
- **A touchscreen no longer crashes the client.**
- **On a desktop whose compositor cannot share GPU buffers** (some software
  or headless setups), Roblox uses OpenGL instead of drawing nothing, and the
  grey screen when typing into a box with no Vulkan is fixed.
- **A game that hangs while closing is stopped after 10 seconds.**
- **Older Roblox builds load again** (2.702 needed `__strrchr_chk`).

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **Most of this has not been played in Stacked.** If the keyboard still dies
  after joining, run with `CORDIAL_TRACE_KEYS=1`, press W, and attach the W
  `[cordial] key` lines to [an issue](https://github.com/DamnShabu/stacked/issues).
  That setting prints every key you type, passwords included, so share only
  those lines.
- **Recording has not been run in Stacked.** Resizing the window while
  recording now skips a few frames rather than freezing the game; that is
  tested only against a stand-in encoder.
- **A missing or unplugged `audio_input` microphone falls back to the default
  one**, saying so only in the client's output.
- **In fullscreen, one row of pixels is left to the desktop**, which may stop
  some compositors from showing the game directly and cost a little
  performance. Not measured.
- **Pointer lock on Hyprland and KDE Plasma is unchanged.**
- **The Steam Deck startup crash is not understood.**
- **Clients the Roblox manager starts still get no crash report**; see
  [0.21.12](v0.21.12.md).

[`docs/known-issues.md`](../known-issues.md) says where each upstream bug
stands.
