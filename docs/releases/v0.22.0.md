# Stacked 0.22.0

This release brings over fixes Cordial made after Stacked forked from it.
None of them has been tried on a real game in Stacked yet; each line says what
it was checked with upstream.

- **Movement keys should work straight after joining a game.** WASD and Space
  sometimes did nothing until the character respawned. While a game starts,
  Stacked now nudges the engine with the pointer's position, which upstream
  measured as walking in 4 of 4 joins against 0 of 18 without it.
  `CORDIAL_NO_GAME_SEED=1` turns it off if you suspect it.
- **On X11, a held key is one press.** Auto-repeat reached the game as a release
  and a press over and over, so a hold-to-interact bar kept restarting.
- **On X11, the camera no longer spins or jumps.** Mouse movement that queued
  up while the game was busy was counted several times over.
- **A touchscreen no longer crashes the client.** Tested upstream with a
  simulated touchscreen only.
- **A game that hangs while closing is stopped after 10 seconds** and exits with
  status 124, which the crash report now knows is not a crash.
- **Resizing into or out of fullscreen on Wayland should no longer crash**,
  and the game redraws
  while you drag the window's edge instead of only when you stop.
- **A log-channel FastFlag set to a bare number is warned about at launch**
  when that channel is known to go silent with one. See
  [fastflags](../fastflags.md).

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **None of the above has been played in Stacked.** The test suite passes; the
  fixes were measured in Cordial, not here. If the keyboard still dies after
  joining, run with `CORDIAL_TRACE_KEYS=1` and attach the `[cordial] key` lines
  from pressing W to [an issue](https://github.com/DamnShabu/stacked/issues).
- **Pointer lock on Hyprland and KDE Plasma is unchanged.** Cordial fixed both
  differently from Stacked's own attempt, and merging the two needs testing on
  those desktops.
- **Text boxes in fullscreen and the grey screen when typing a camera
  sensitivity are not brought over yet.**
- **The Steam Deck startup crash is not understood.**
- Everything still listed in the [0.21.12 notes](v0.21.12.md) except the
  keyboard line, and [`docs/known-issues.md`](../known-issues.md) says where
  each upstream bug stands.
