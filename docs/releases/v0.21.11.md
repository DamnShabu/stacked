# Stacked 0.21.11

**`stacked desktop install` works from the AppImage.** Before, it added no
menu entry, and the website's Play button pointed at a file that existed only
while the AppImage was running. It now writes an entry that runs the
`.AppImage` file itself, so keep the file where it is, or run the command
again after moving it.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **The AppImage fix has not been run from a real AppImage.** Its tests pass.
  If the menu entry or the Play button still does nothing after
  `./Stacked-*.AppImage desktop install`, report it with the output of that
  command.
- From [0.21.10](v0.21.10.md): how much sooner a launch reaches the home screen
  has not been timed, and the fullscreen-on-start fix has not been tested
  against the real freeze.
- From [0.21.9](v0.21.9.md): whether ETC2 decoding sharpens textures in a game
  has not been tested, and NVIDIA's own driver does not have the decoder.
- From [0.21.8](v0.21.8.md): Roblox's dynamic resolution may still soften 3D on
  some accounts, and with two input seats only the first drives the game.
- From [0.21.7](v0.21.7.md): hiding the window has been tried only on niri.
- From [0.21.6](v0.21.6.md): the frame rate may dip to 60 for a few seconds
  every two minutes.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies, and
[`docs/known-issues.md`](../known-issues.md) says where each one stands.
