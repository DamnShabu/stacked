# Stacked 0.21.9

**An attempt at blurry 3D textures and cursors on AMD and some Intel
graphics.** These cards cannot read ETC2, the compressed texture format phones
use, so Roblox's engine was told it was missing. Sober, on the same card, has
it emulated, and its textures are the crisp ones. Stacked now asks the Mesa
driver to decode ETC2 itself, so the engine sees the same support Sober gives
it. Your engine log shows `Caps: Texture: DXT 1 PVR 0 ETC1 1 ETC2 1` where it
used to show `ETC1 0 ETC2 0`.

To turn it off, launch with `vk_require_etc2=false`.

**The engine is told how much memory this computer really has.** Stacked
reported a fixed 8 GB phone with a 256 MB app budget. It now reports your
real RAM, and a 4096 MB budget as Sober does. `CORDIAL_LEGACY_MEMORY_CLASS=1`
brings back the old numbers.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **Whether this sharpens textures in a game has not been tested.** It was
  tested signed out, where the engine loads no ETC2 texture. If 3D textures or
  a game's custom cursor are still soft, please say so on the issue tracker.
- NVIDIA's own driver does not have this decoder, so NVIDIA cards are not
  affected by this change.
- From [0.21.8](v0.21.8.md): Roblox's dynamic resolution may still soften 3D on
  some accounts, and with two input seats only the first drives the game.
- From [0.21.7](v0.21.7.md): hiding has been tried only on niri.
- From [0.21.6](v0.21.6.md): the frame rate may dip to 60 for a few seconds
  every two minutes.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies, and
[`docs/known-issues.md`](../known-issues.md) says where each one stands.
