# Stacked 0.21.8

**Clicks and keys reach the game again if your desktop has a second input
seat.** On such a desktop, Stacked attached its mouse and keyboard to the
last seat on offer, so the window showed the game but nothing you did reached
it. A niri patched with an extra `agent` seat is one example. Stacked now uses
the first seat, which is your own. Desktops with one seat, which is nearly all
of them, are unaffected.

**A launcher can ask for a graphics-quality preset.** Set `CORDIAL_QUALITY` to
`low`, `medium` or `max` for one client, and Stacked sets the matching
FastFlags beneath that profile's own `flags.json`. The Roblox manager's
performance levels use this. `max` keeps the engine at its top quality level
rather than letting it step quality down to chase a high frame rate, and asks
for no dynamic resolution scaling. [fastflags.md](../fastflags.md) lists what
each level sets.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- With two seats, only the first can drive the game. The second seat still
  works in Stacked's own windows.
- The seat fix was tested in a nested niri on the landing page, not yet on a
  real desktop inside a game.
- Turning dynamic resolution off is not measured. Roblox enrols some accounts
  through an experiment, and that enrolment outranks flags, so `max` may still
  look soft in 3D on those accounts. A changed preset may only fully apply from
  the second launch, because the engine starts from its cached flags.
- Whether `max`'s anti-aliasing and texture settings change a 3D frame is not
  measured.
- From [0.21.7](v0.21.7.md): hiding has been tried only on niri.
- From [0.21.6](v0.21.6.md): the frame rate may dip to 60 for a few seconds
  every two minutes.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies, and
[`docs/known-issues.md`](../known-issues.md) says where each one stands.
