# Cordial 0.20.0 — shaders, text boxes

## Shaders

Settings has a new **Shaders (vkBasalt)** switch. Turn it on to add
sharpening and anti-aliasing over the game. It appears once
[vkBasalt](https://github.com/DadSchoorse/vkBasalt) is installed. On the
Flatpak, that means
`flatpak install org.freedesktop.Platform.VulkanLayer.vkBasalt`.

Each profile gets its own config file the first time you turn the switch
on. Edit it to change the effects; Cordial never overwrites it once it
exists. [docs/shaders.md](https://github.com/luohoa97/cordial/blob/main/docs/shaders.md) has the install steps for each
distribution and says where the file is.

## Text boxes

- Multi-line text boxes, such as code and note editors in games, now get a
  proper multi-line editor instead of a single line stretched to the box's
  height.
- Resizing the window or switching fullscreen while typing no longer leaves
  the text you type at the old position, or off the edge of the window.
- Text boxes a game aligns to the right or to the centre are no longer
  aligned to the wrong side.
- The title bar no longer turns see-through while a text box is focused.

## What is still broken

**The signed-in startup freeze is not fixed.** It comes in bursts: some
batches of ten launches in testing had none, and others had several. The
cause has been narrowed to a wait inside the Roblox client during startup,
but not yet found.

**The screen may still grey out when a text box takes focus in fullscreen**
([#53](https://github.com/luohoa97/cordial/issues/53)). The multi-line editor
above may fix the case that was reported, but that has not been confirmed in
a game yet.

**Games that put the cursor in a text box for you, such as some typing
games, may not accept typing.** No cause has been found in Cordial yet. If a
game does this to you, please say which one.

**Shaders are untested in a game and on NVIDIA and AMD graphics**, and
vkBasalt's on/off key does nothing on Wayland, which is Cordial's default.
Use the switch in Settings instead.

**A game's `DF` FastFlags, such as `DFIntTaskSchedulerTargetFps`, can reset
partway through a session**, because the Roblox client refreshes them from
Roblox's servers on its own schedule.

**Some games show the mobile (touch) interface.**

Still open from earlier releases:

  ([#44](https://github.com/luohoa97/cordial/issues/44));
- a freeze and crash leaving fullscreen
  ([#39](https://github.com/luohoa97/cordial/issues/39));

  ([#35](https://github.com/luohoa97/cordial/issues/35));

  ([#56](https://github.com/luohoa97/cordial/issues/56));
- a rare crash just after startup
  ([#63](https://github.com/luohoa97/cordial/issues/63)).

ARM64 builds are still untested on real hardware. VR is not supported.
