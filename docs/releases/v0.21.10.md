# Stacked 0.21.10

**The game no longer waits on a download before it starts.** If you hadn't
played in the last six hours, every client fetched Roblox's settings, about
1.3 MB, before the engine could go on. On a slow or flaky connection that
could take up to twenty seconds. Now a copy up to a week old starts the game
straight away, and a fresh one downloads in the background for next time.
A copy older than a week is still fetched first, as before.

**GameMode no longer holds up startup.** When GameMode is installed, Stacked
asks it for the performance governor without waiting for the answer.

Also in this release, rustls, which Stacked uses for HTTPS, is updated to
0.23.46.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **How much sooner a launch reaches the home screen has not been timed on a
  real launch.** To see it, look for the line
  `client settings: load_base took Nms` in a client's log after a launch more
  than six hours since your last.
- A settings copy up to a week old can carry flags Roblox has since changed.
  It is used for one launch while the fresh copy downloads.
- From [0.21.9](v0.21.9.md): whether ETC2 decoding sharpens textures in a game
  has not been tested, and NVIDIA's own driver does not have the decoder.
- From [0.21.8](v0.21.8.md): Roblox's dynamic resolution may still soften 3D on
  some accounts, and with two input seats only the first drives the game.
- From [0.21.7](v0.21.7.md): hiding the window has been tried only on niri.
- From [0.21.6](v0.21.6.md): the frame rate may dip to 60 for a few seconds
  every two minutes.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies, and
[`docs/known-issues.md`](../known-issues.md) says where each one stands.
