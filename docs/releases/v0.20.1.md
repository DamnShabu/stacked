# Cordial 0.20.1: Flatpak updates work again

**If you installed the Flatpak, `flatpak update` had stopped finding new
versions.** The Flatpak repository has not been updated since 0.18.0. The
stable channel stayed at 0.18.0, and the `master` channel was stuck there too
until earlier today. This release puts both channels on the current version:

```bash
flatpak update io.github.luohoa97.Cordial
```

Everything new in [0.19.0](https://github.com/luohoa97/cordial/releases/tag/v0.19.0)
and [0.20.0](https://github.com/luohoa97/cordial/releases/tag/v0.20.0) arrives
with it: private servers, plugins that apply without restarting, the Shaders
switch, and the text box fixes. Those releases' notes still describe what is
broken, and nothing on that list has changed.

The Arch package repository no longer includes the `cordial-debug` package,
which was too large to host there. It is still attached to each release on
GitHub.
