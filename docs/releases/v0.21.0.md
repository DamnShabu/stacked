# Stacked 0.21.0: the first Stacked release

Stacked is a fork of Cordial. It runs the same engine, and anything you had
in Cordial carries over: profiles, sign-ins, FastFlags and settings. What's
different is that there is no launcher window. `stacked` is a command, and the
game's window is the only window.

## Getting started

```bash
stacked desktop install   # app menu entry, and the website's Play button opens Stacked
stacked doctor            # checks this machine and says what to fix
stacked                   # play
```

The first `stacked` downloads Roblox (or uses Sober's copy, if you have one)
and checks it against Roblox's own signature. After that, each launch installs
a newer Roblox build first if one is out, because Roblox turns old clients
away. `stacked play --no-update` skips the check, and
`stacked config set auto_update false` turns it off.

## New

- **`stacked doctor`** checks the display, Vulkan, sound, the keyring,
  GameMode, the browser's Play button, disk space and the Roblox build, and
  prints the command that fixes each problem it finds.
- **FastFlags from the command line.** `stacked flags set NAME VALUE` checks
  the value against the flag's type (`FFlag…` takes true or false, `FInt…` a
  whole number) before saving. `stacked flags import --sober` copies the flags
  you set in Sober, `import file.json` takes a Bloxstrap export, and
  `stacked flags edit` saves only if what you wrote is valid.
- **Plugin preferences:** `stacked plugins prefs ID` lists them, and
  `stacked plugins prefs ID KEY VALUE` sets one.
- **Tab completion** for bash, zsh and fish: `stacked completions bash`.
  A mistyped command or setting gets a "did you mean".
- **The cursor stays on the game's screen in fullscreen**, even in menus.
- **The frame-rate target follows your screen's refresh rate** rather than
  the engine's 60. `stacked config set fps_cap 90` fixes it at a number.
- **Its own look** for the title bar. `stacked config set theme system` gives
  you your desktop's.
- The Discord status button links to Stacked rather than Cordial.

## Fixed

- A launch could extract the 116 MB engine again every time, after the
  Roblox build moved from Sober's folder to Stacked's or was reinstalled at
  the same version.
- A Roblox APK replaced at the same path, or a different one chosen with
  `roblox.apk`, could start once without its signature being checked.
- A plugin with code was switched off only in the profile you installed it
  from, and ran in every other profile. It is now off everywhere until you
  enable it.
- A plugin packaged the way `plugins/README.md` describes was refused with
  "an entry has no path".
- `stacked update` downloaded the build you already had. `--force` still
  does, if you want that.
- A mistyped `--profile` created a new profile and put your change there.
- X11: keys held when the window lost focus stayed held.
- The client could hang on exit. It now gives the engine 10 seconds, then
  exits anyway.

## What is still broken

**Updating Roblox at launch has not been seen working end to end.** Each part
is tested, but the download mirror wasn't reachable from where this release
was prepared. If the update fails, the build you have starts, and
`stacked update` tries again.

**Untested:** running above 60 fps on a faster screen (the flag Stacked sets
is known to lower the frame rate, and raising it hasn't been measured), and
cursor confinement on a real multi-monitor desktop.

Still open from Cordial, and they apply here:
- no window on COSMIC, KWin or some wlroots compositors
  ([cordial#38](https://github.com/luohoa97/cordial/issues/38));
- a crash on first touch with a touchscreen
  ([cordial#36](https://github.com/luohoa97/cordial/issues/36));
- a crash at launch on some machines, including the Steam Deck
  ([cordial#35](https://github.com/luohoa97/cordial/issues/35));
- the keyboard sometimes dead after joining an experience
  ([cordial#64](https://github.com/luohoa97/cordial/issues/64));
- the signed-in startup freeze, which comes in bursts.

[`docs/known-issues.md`](../known-issues.md) says where each one stands and
what to run if you can help.
