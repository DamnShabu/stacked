# Stacked 0.21.7

A client's window can now be hidden and brought back while the game keeps
running. The Roblox manager uses this for its new hide button. From a terminal,
`kill -USR1 <pid>` hides a client and `kill -USR2 <pid>` shows it again.

A hidden window is gone from the screen and the taskbar, not minimised, so it
works on niri and any other compositor. While hidden, the client draws at
most 10 frames a second. Measured on niri: about 3 a second hidden, against
about 70 shown.

Programs that start clients can read `<profile>/window-state` (`shown` or
`hidden`) for as long as a client runs.
[ADR-046](../adr/ADR-046-a-launcher-hides-the-window-with-a-signal.md) has the
details.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- Hiding has been tried only on niri. X11, and the OpenGL renderer
  (`CORDIAL_GRAPHICS=gles`), have not been tested, and the OpenGL renderer is
  not slowed down while hidden.
- Before 0.21.7, `SIGUSR1` ended a client outright. A script that sends it to
  an older client will close that client.
- From [0.21.6](v0.21.6.md): the frame rate may dip to 60 for a few seconds
  every two minutes.
- From [0.21.5](v0.21.5.md): the text box editor on niri may send clicks to the
  game. Not yet tested.
- From [0.21.4](v0.21.4.md): web pages may not load over HTTPS from the
  AppImage on non-Debian systems, and two people running the same version on
  one computer cannot both open web windows.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies. In short:

- updating Roblox at launch has not yet been seen working end to end;
- no window on COSMIC, KWin or some wlroots compositors;
- a crash at launch on some machines, including the Steam Deck;
- the keyboard is sometimes dead after joining an experience;
- a startup freeze on signed-in profiles, which comes in bursts.

[`docs/known-issues.md`](../known-issues.md) says where each one stands.
