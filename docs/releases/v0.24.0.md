# Stacked 0.24.0

Stacked now looks like Headcount, and shows you something while it starts.

## What changed

- **A new look, shared with Headcount.** The game window is near-black with a
  red accent instead of brown and amber, and the icon is new: a white block
  with Headcount's face in front of a red one. `stacked config set theme
  system` still gives you your desktop's own colours.
- **A slimmer title bar.** It is 32 pixels tall instead of 46, and 26 with
  `title_bar compact`. The version sits beside the name in a quieter colour,
  and the window buttons stay flat until you hover them.
- **A loading window.** Between clicking Play and the game window opening, a
  small card shows the icon and a progress bar with the step Stacked is on.
  `CORDIAL_SPLASH=off` turns it off.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use Headcount,
press Update, then launch your accounts again.

## What is still broken

- **The loading window has only been seen in a test window**, not in front of
  a real launch. If it stays up over the game, or a launch is slower with it
  than with `CORDIAL_SPLASH=off`, please report it with the log.
- **The bar moves between steps, not during one.** A slow step, such as
  fetching settings on a bad connection, shows as the bar standing still.
- **It does not cover the very first moments of a launch**, or the unpacking
  a first run does. Those still show nothing.
- **The loading window is Wayland only.** On X11 there is none.
- Everything listed under [0.23.3](v0.23.3.md#what-is-still-broken) still
  applies.
