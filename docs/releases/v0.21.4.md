# Stacked 0.21.4

Fixes the client crashing when you open a game's Servers list from the
AppImage. The same crash hit any Roblox page that opens in a web window.

## What was wrong

The AppImage carries its own copy of WebKitGTK, the engine behind those
windows. WebKitGTK starts helper programs to load a page, and it looked for
them at a fixed path that existed only on the machine the AppImage was built
on. When they were not there, WebKitGTK stopped the whole process. That
affected the Roblox manager's Update Stacked, and most distributions other
than Debian and Ubuntu.

0.21.4 copies the helpers to a private directory under `/tmp` before a web
window opens, and its WebKitGTK looks for them there. If that cannot be done,
for example when `/tmp` does not allow running programs, the window does not
open and the client keeps running. The reason is printed, starting with
`[webview] cannot open a web window:`.

The .deb, .rpm, Arch package and Flatpak use your system's WebKitGTK and were
never affected.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked.

## What is still broken

- **Web pages may not load over HTTPS from the AppImage on non-Debian
  systems.** The window opens and shows an error page instead of the page,
  because the AppImage carries no TLS module for WebKitGTK. Through the Roblox
  manager the pages load.
- If two people on one computer run the same Stacked version at the same time,
  only the first can open web windows. The second is told why.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies. In short:

- updating Roblox at launch has not yet been seen working end to end;
- no window on COSMIC, KWin or some wlroots compositors;
- a crash at launch on some machines, including the Steam Deck;
- the keyboard is sometimes dead after joining an experience;
- a startup freeze on signed-in profiles, which comes in bursts.

[`docs/known-issues.md`](../known-issues.md) says where each one stands.
