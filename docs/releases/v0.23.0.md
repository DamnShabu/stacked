# Stacked 0.23.0

More of Cordial's fixes since the fork, this time for the mouse, controllers,
plugins and the command line, plus a stability pass of Stacked's own. **None of
it has been played in Stacked yet**: the test suite passes, and the ports were
measured upstream rather than here.

## Mouse and keyboard

- **Pointer lock should now work on Hyprland and KDE Plasma.** Dragging the
  camera with the right button should no longer drop the button or drift. On
  Hyprland, `CORDIAL_DRAG_LOCK=0` turns the new behaviour off.
- **The camera follows your system's mouse acceleration** by default, so it
  may feel different from 0.22. `stacked config set pointer_acceleration
  unlockedcursor` gives raw camera movement again.
- **Pressing a second mouse button no longer ends the first one's drag.**
- **On X11, holding a key repeats it as presses only**, so hold-to-interact
  bars no longer restart.
- If the input loop stalls for a second, the log now says so and where the
  time went.

## Controllers

- **Sticks and buttons are mapped from what the controller reports**, which
  fixes pads with a four-button D-pad, a Z/RZ right stick, and the DualShock 4.
  `CORDIAL_GAMEPAD_AXES` overrides the mapping for a pad that is still wrong.
- **Pushing a stick up or down no longer moves menus sideways.**
- **Controllers work in the Flatpak**, which now asks for input-device access.
- Controllers beyond the fourth are found, and the development control socket
  can switch them on or off during a game. See [controllers](../controllers.md).

## Plugins

- **A plugin that fails to start is no longer retried every second.** It waits
  longer each time, or until Deno, the plugin or its permissions change.
- **A plugin update that asks for new permissions stays stopped** until you
  grant them, instead of starting with the old ones.
- `stacked plugins enable` lists the permissions the plugin still lacks, with
  the command to grant each.

## Command line

- **`stacked logs --zip` saves one archive to attach to a bug report**, with
  account cookies, tickets, user IDs and usernames removed. It never includes
  a core file and never overwrites an existing file.
- **`stacked flags import` skips a bad entry instead of refusing the whole
  file**, and names what it skipped. FLog severities such as `"Warning,6"` are
  accepted, and `--from sober` imports Sober's flags.
- **Inside gamescope the game opens on X11.** When no window can be opened,
  Stacked exits with status 5 and `stacked play` says why, instead of
  reporting a crash. `stacked doctor` warns when it detects gamescope.
- `stacked doctor` finds Vulkan drivers on NixOS.

## Stability

- Input no longer leaks memory with every mouse movement and key press.
- A busy ALSA or OSS sound device is reported as unavailable instead of
  hanging startup.
- Voice chat closes a sound stream before opening another, and stopping the
  microphone no longer risks a crash.
- A log line that is not valid UTF-8 no longer stops game events (joins,
  leaves, Discord presence) for the rest of the session, nor kills the client.
- A plugin that stops reading can no longer stall the others, and plugins are
  stopped when the client exits, even without bubblewrap.
- Downloads give up after a stalled connection instead of waiting forever.
- Roblox's saved settings survive values longer than 8 KiB and a failed write.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **None of this has been played in Stacked.** The pointer-lock, controller
  and audio changes in particular were checked only by building and testing,
  and no controller was attached. If one of them is worse for you, run
  `stacked logs --zip` and attach the archive to
  [an issue](https://github.com/DamnShabu/stacked/issues).
- **The camera's feel may have changed** because of mouse acceleration. That
  is deliberate; the setting above turns it off.
- **`logs --zip` leaves a URL looking like `?<query removed><redacted>`.**
  Nothing private is left in it; it only reads oddly.
- **Nothing in the command line shows "update needs approval" yet**; the
  plugin simply stays stopped until `stacked plugins grant` is run.
- **The Steam Deck startup crash is not understood.**
- **Clients the Roblox manager starts still get no crash report**; see
  [0.21.12](v0.21.12.md).

[`docs/known-issues.md`](../known-issues.md) says where each upstream bug
stands.
