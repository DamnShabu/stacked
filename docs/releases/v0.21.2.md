# Stacked 0.21.2

The first Stacked release with packages you can download. 0.21.0 and 0.21.1
were tagged but came with nothing to install. The application is the same as
0.21.1, so everything the [0.21.0 notes](v0.21.0.md) describe applies.

## Which file to download

- **Any distribution:** the `.AppImage` for your architecture (x86_64 or
  aarch64). Make it executable and run it.
- **Debian and Ubuntu:** the `.deb`.
- **Fedora:** the `.rpm`.
- **Arch (x86_64):** the `.pkg.tar.zst`, installed with `pacman -U`.
- **Flatpak:** the `.flatpak` bundle, installed with `flatpak install --user`.

Every file is signed with Sigstore; its `.cosign.bundle` sits next to it.

After installing, run:

```bash
stacked desktop install   # app menu entry, and the website's Play button opens Stacked
stacked doctor            # checks this machine and says what to fix
stacked                   # play
```

## What is still broken

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies. In short:

- updating Roblox at launch has not yet been seen working end to end;
- no window on COSMIC, KWin or some wlroots compositors;
- a crash at launch on some machines, including the Steam Deck;
- the keyboard is sometimes dead after joining an experience;
- a startup freeze on signed-in profiles, which comes in bursts.

[`docs/known-issues.md`](../known-issues.md) says where each one stands.
