# Stacked 0.21.3

Fixes the AppImage opening to an empty window. The title bar appeared, the
area below it stayed blank, and nothing was ever drawn.

## What was wrong

The 0.21.2 AppImage carried its own copy of the Wayland client libraries,
older than the ones a current Mesa is built against. Loaded ahead of yours,
they stopped every Vulkan and EGL driver from loading, so Roblox had no GPU
to draw with. It affects any system whose Mesa is built against Wayland 1.24
or newer, and it affects the Roblox manager's Update Stacked, which installs
the AppImage.

0.21.3 leaves those libraries to your system, the same as it already did for
the rest of the graphics stack. The .deb, .rpm, Arch package and Flatpak were
never affected.

If you see an empty window, run Stacked from a terminal and look for
`undefined symbol: wl_fixes_interface` or
`health: 0 presents ... nothing was drawn`. Either one means this bug.

## Which file to download

The same as [0.21.2](v0.21.2.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked.

## What is still broken

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies. In short:

- updating Roblox at launch has not yet been seen working end to end;
- no window on COSMIC, KWin or some wlroots compositors;
- a crash at launch on some machines, including the Steam Deck;
- the keyboard is sometimes dead after joining an experience;
- a startup freeze on signed-in profiles, which comes in bursts.

[`docs/known-issues.md`](../known-issues.md) says where each one stands.
