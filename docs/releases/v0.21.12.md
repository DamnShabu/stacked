# Stacked 0.21.12

**A crash now leaves a report behind.** When Roblox dies under `stacked`,
started from a terminal, the menu entry or the website's Play button, the last
200 lines it printed are saved in the profile's `crashes` folder, beside the
build and system details a bug report needs. `stacked logs --crash` shows the
newest one, and the crash message names the file. The newest 20 are kept.
Lines about your saved sign-in are left out, as they already were on the
crash message.

Before this, a crash outside a terminal left nothing on disk, and even in a
terminal the crash summary could miss the client's last lines.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **Clients the Roblox manager starts do not get crash reports from this.**
  The manager runs the engine itself and writes its output to its own
  `logs/<account>.log`, keeping only the previous launch. Copy that file before
  launching the account twice more.
- **Random crashes are not fixed.** This release makes them reportable. Attach
  `stacked logs --crash` to [an issue](https://github.com/DamnShabu/stacked/issues).
- **The keyboard sometimes stops working after joining a game or switching
  server, while the mouse keeps working.** Not yet diagnosed. If it happens,
  note whether clicking another window and back brings it back.
- Crash reporting was tested with a stand-in client that crashes on purpose,
  not with a real engine crash.
- From [0.21.11](v0.21.11.md): `desktop install` from the AppImage has not been
  run from a real AppImage.
- From [0.21.10](v0.21.10.md): how much sooner a launch reaches the home screen
  has not been timed, and the fullscreen-on-start fix has not been tested
  against the real freeze.
- From [0.21.9](v0.21.9.md): whether ETC2 decoding sharpens textures in a game
  has not been tested, and NVIDIA's own driver does not have the decoder.
- From [0.21.8](v0.21.8.md): Roblox's dynamic resolution may still soften 3D on
  some accounts, and with two input seats only the first drives the game.

Everything in the "What is still broken" section of the
[0.21.0 notes](v0.21.0.md) still applies, and
[`docs/known-issues.md`](../known-issues.md) says where each one stands.
