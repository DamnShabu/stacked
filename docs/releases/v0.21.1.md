# Stacked 0.21.1

A packaging fix. Stacked itself behaves exactly as it did in 0.21.0, so if
you already have 0.21.0 installed there is nothing new to see.

## Fixed

- **Building the AppImage from a fresh clone.** A clone made without
  `--recursive` got several minutes into
  `packaging/appimage/build-appimage.sh` and then failed with
  `third_party/mcpelauncher-linker is not checked out`, or with
  `'android/versioning.h' file not found` when the submodules were only half
  there. The script now checks for them and runs
  `git submodule update --init --recursive --force` before it builds. That
  `--force` throws away local edits inside the submodules, and only runs when
  something is missing.

## What is still broken

- **Everything listed in the [0.21.0 notes](v0.21.0.md)** still applies.
- **The AppImage has to be built on Ubuntu 24.04**, as the release workflow
  does. Building it in a Nix shell bundles `/nix/store` libraries, and the
  result is expected to run only on the machine that built it. That is
  `INFERRED`: nobody has tested such a build on a second machine.
