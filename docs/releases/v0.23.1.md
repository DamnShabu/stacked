# Stacked 0.23.1

One fix, for the Roblox manager's quick join.

## What changed

- **Picking a game in the Roblox manager and launching should join it
  again.** Since 0.22.0, a client the manager started into a game sometimes
  stopped on the Roblox home screen instead. A startup step that restarts
  Roblox's app had moved to run while the home screen was already coming up,
  and it could throw the join away. On an ordinary launch it now runs before
  the game starts, as it did up to 0.21.12.

## Which file to download

The same as [0.21.3](v0.21.3.md): the `.AppImage` for any distribution, or the
`.deb`, `.rpm`, Arch package or `.flatpak` for yours. If you use the Roblox
manager, press Update Stacked, then launch your accounts again.

## What is still broken

- **This fix has not been seen working in a game.** It was built and tested,
  and the cause was read from a log of a launch that joined, not one that
  failed. If a manager launch still stops on the home screen, run
  `stacked logs --zip` and attach the archive to
  [an issue](https://github.com/DamnShabu/stacked/issues).
- Everything listed under [0.23.0](v0.23.0.md#what-is-still-broken) still
  applies.
